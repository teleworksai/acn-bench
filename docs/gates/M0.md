## Known limitations carried past M0

- **The mock is a model, with stated differences** (SPEC 100 P4-12). Shuffling tools changes which tool the mock calls (#26); explicit breakpoints have no lookback to earlier blocks (#32).
- **Open `spec-conflict` issues on SPEC 080** remain open: #10, #13, #15 and #18. None blocks a mock-gated verdict.
- **Bundle creation is not staged** (#20): a crash mid-write can leave a run ID that blocks a rerun.
